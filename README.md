# NGS RNA-seq Analysis Pipeline

Personal project for analyzing RNA-seq data, from raw read quality control to gene expression quantification.

## Objective
Build and run a complete RNA-seq analysis pipeline using standard bioinformatics tools, as a hands-on exercise to develop skills in NGS data analysis.

## Project Structure

## Pipeline
1. Quality Control (FastQC)
2. Trimming (fastp)
3. Alignment (STAR)
4. Gene expression quantification
5. Downstream analysis (pandas / R)

## Tools
- FastQC
- fastp
- STAR
- samtools
- conda (environment management)
